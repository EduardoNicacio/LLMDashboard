# Contributing

Thank you for your interest in contributing to LLMDashboard. This project collects single-file HTML dashboards generated by different LLMs from identical prompts, enabling head-to-head comparison of model outputs.

## Prerequisites

- A GitHub account
- A Hugging Face account (to download model weights if running models locally)
- Familiarity with HTML, CSS, and JavaScript
- Understanding of the MIT License terms

## How to Contribute

1. **Fork** this repository.
2. **Clone** your fork:

   ```bash
   git clone https://github.com/your-username/LLMDashboard.git
   cd LLMDashboard
   ```

3. **Create a branch** following the naming pattern `feature/[provider]-[model]-[param-count]-dashboard` (e.g., `feature/google-gemma4-12b-dashboard`).
4. **Generate a dashboard** using any LLM with the corresponding prompt from the `/prompts` directory. The output must be a single self-contained HTML file (all CSS and JS inline).
5. **Add your file** to the appropriate `/src/<dashboard-type>/` directory using the naming convention `[provider]-[model]-[param-count]-<dashboard-type>.html`.
6. **Add a screenshot** to `img/screenshots/<dashboard-type>/` with the same filename but a `.png` extension.
7. **Commit** with a clear message (see commit convention below).
8. **Push** to your branch:

   ```bash
   git push origin feature/google-gemma4-12b-dashboard
   ```

9. **Open a Pull Request** describing the model used, the dashboard type, and any notable characteristics of the output.

## File Naming Convention

```txt
[provider]-[model-name]-[param-count]-<dashboard-type>.html
```

Examples:

- `alibaba-qwen3.5-9b-ai-command-center.html`
- `deepseekai-deepseek-v4-flash-weather-dashboard.html`
- `openai-gpt-5.5-project-management-dashboard.html`

Place each file in the corresponding `/src/<dashboard-type>/` subdirectory:

- `src/ai-command-center/`
- `src/financial-dashboard/`
- `src/product-landing-page/`
- `src/project-management-dashboard/`
- `src/weather-dashboard/`

## Quality Standards

- The HTML file must be **completely self-contained** - no external files beyond CDN libraries (Bootstrap, Tailwind, Chart.js, Font Awesome, etc.).
- All external CDN resources should use pinned versions (not `@latest`) for reproducibility.
- The dashboard should render correctly in modern browsers (Chrome, Firefox, Edge).
- Verify that interactive controls (tabs, filters, sorting, theme toggles) work before submitting.
- Screenshots should capture the dashboard in its default state at 1920x1080 resolution.

## Commit Message Convention

We use [Conventional Commits](https://www.conventionalcommits.org/):

```txt
<type>(<scope>): <description>
```

Examples:

- `feat(weather-dashboard): add deepseekai-deepseek-v4-flash output`
- `fix(ai-command-center): correct chart resize on tab switch`
- `docs: update README with new model results`

## Pull Request Template

Include in your PR description:

### Summary

What model and dashboard type you are contributing.

### Model Details

- Provider and model name
- Parameter count (total and active if MoE)
- Quantization/precision used
- Inference framework used (llama.cpp, vLLM, SGLang, API, etc.)

### Verification

- Did you open the HTML file in a browser and test all interactive controls?
- Are there any known issues or quirks in the output?

### Screenshots

Attach one or more screenshots showing the dashboard.

## Reporting Issues

If you find a bug in an existing dashboard or have a suggestion for a new prompt:

1. Go to the **Issues** tab.
2. Create a new issue with a clear title and description.
3. Include the file path and a description of the problem.

## Code of Conduct

- Be respectful and inclusive.
- Do not share personal contact information or private data in PRs or comments.
- Respect the MIT License terms.
