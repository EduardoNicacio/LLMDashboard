# LLMDashboard

A collection of **95 single-file HTML dashboards** generated by **19 different LLMs** across **5 dashboard types**. Each dashboard was built from the same prompt per category, allowing head-to-head comparison of model outputs - code quality, UI polish, feature completeness, and design sensibility. The five dashboard types are:

- **AI Command Center** - Head-to-head model testing arena with performance charts, hardware monitoring, and matchup results.
- **Financial Dashboard** - Side-by-side financial analysis with company comparisons, interactive charts, and market data feeds.
- **Product Landing Page** - Parody product launch page for a fictional open-weight model release.
- **Project Management Dashboard** - Enterprise portfolio manager with project tracking, timelines, budgets, and risk matrices.
- **Weather Dashboard** - Premium weather app with city search, forecasts, charts, and dynamic backgrounds.
