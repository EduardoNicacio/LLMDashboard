# Readme

## Contributing

We welcome contributions! If you have additional high-quality LLM-generated dashboards:

1. Fork this repository.
2. Create a branch named `feature/[provider]-[model]-[param-count]-dashboard`.
3. Add your content to the `/src` folder.
   - Please follow the existent naming conventions for all your files.
4. Submit a Pull Request with a brief description of the output you've added.
